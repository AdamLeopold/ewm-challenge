DATA / RESEARCH

让世界模型持续进步

参赛成果与经授权收集的运行数据，以及单独授权的 Agent 程序、容器镜像和模型资料，将依照隐私条款与授权范围，用于经济世界模型的训练、评测与持续改进。

01 / MATERIALS

明确每一类资料的授权范围

参赛成果

空间规划、政策、报告及其他提交成果，可支持策略学习、风险治理与城市规划研究。

运行与评测数据

经授权的观察、动作、运行轨迹与评测结果，有助于比较统一条件下的决策表现。

Agent 程序与模型资料

独立研究授权可涵盖源码、容器镜像、模型资料与权重，并分别记录各类资料的授权范围。

Agent 交互内容

提示词、对话与生成内容可通过单独、明确的授权选择纳入研究。

02 / AUTHORISATION

研究用途单独选择

参赛与研究授权

正式报名与提交环节将单独列出研究用途选择，初始保持未选择。队伍可按资料类别确定授权范围；参赛资格、评分与名次统一依照比赛规则确定。

提交环节说明清楚

相应提交服务的隐私条款将说明各类资料的用途、接收方、保存安排与授权管理方式。

03 / IMPROVEMENT

从参赛评测走向更好的世界模型

训练

从经授权的策略、规划与决策轨迹中学习。

评测

通过可复现实验比较决策与结果。

改进

将研究发现用于经济世界模型的后续迭代。

浏览器 Demo 提供教学与规划体验。城市政策草稿保存在本机，环境视图读取香港公开天气报告。正式报名与提交服务将提供对应的隐私条款和授权选择。
