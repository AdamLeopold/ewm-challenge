01 / FOUNDATION

底层：经济世界模型

经济世界模型是一个生成式的经济引擎。它同时刻画形形色色的 Agent 和它们所处的环境，让结果从相互作用中涌现出来，而不是事先假定。

形形色色的 Agent

家庭、企业、投资者、协议和政策制定者，各有自己的判断、约束和决策方式。

会变化的环境

市场、制度与空间。Agent 的决策改变环境，环境又影响它们的下一步决策。

涌现的结果

价格、就业、风险和增长都从交互中产生，包括静态模型看不到的意外。

02 / HOW IT WORKS

一个比赛，一套原则

每个赛道都走同样的流程，不同的只是你的 Agent 被放进哪个世界。

构建

用你喜欢的工具和模型，构建一个 Agent，或者借助 Agent 规划一座城市。

进入世界

它在仿真世界里运行，周围的模拟 Agent 会对它的行为作出反应。

面对未知

提交之后才运行隐藏的情景和冲击，谁都无法事先针对它们调参。

公平比较

所有参赛作品面对同样的条件，结果可以复现。

同一个世界

同一赛道的所有作品，在同一个世界、同一套规则下运行。

隐藏情景

情景在评测之后才公开，分数奖励的是稳健，而不是死记硬背。

Agent 之间

你的 Agent 要在其他 Agent 之间接受检验，而不是在一张空表格里。

可复现

运行条件有记录，结果可以重跑、可以核对。
