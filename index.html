01 / FOUNDATION

经济世界模型如何运转

经济世界模型是一个生成式的经济引擎。它同时刻画形形色色的 Agent 和它们所处的环境，让结果从相互作用中涌现出来，而不是事先假定。

形形色色的 Agent

家庭、企业、投资者、协议和政策制定者，各有自己的判断、约束和决策方式。

会变化的环境

市场、制度与空间。Agent 的决策改变环境，环境又影响它们的下一步决策。

涌现的结果

价格、就业、风险和增长都从交互中产生，包括静态模型看不到的意外。

模型

经济世界模型

  1. L1

    智能底座

    在每个 Agent 体内。LLM 负责信念、推理与语言，RL 负责目标优化与适应。

  2. L2

    经济行为主体

    单个人或企业会怎么做：角色、目标、私有状态、信念更新、决策策略与约束，并用真实行为数据校准偏差与有限理性。

  3. L3

    经济环境与制度

    个体行动怎么变成总体结果：市场机制（出清、拍卖、匹配）、会计与预算约束、政策规则，制度本身也可以内生演化。

  4. L4

    均衡与现实纪律

    模拟结果凭什么可信：对内是数据驱动的生成式均衡（Data-Driven Generative Equilibrium），行为、数据与学到的环境三者在不动点上闭环一致；对外与真实数据持续校准。
