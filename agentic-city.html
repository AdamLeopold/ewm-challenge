划分区域

用自然语言划出区域，说明功能：居住、商业、办公、公共设施等。

建设建筑

建筑或建筑群，有位置、占地面积、高度和功能。

调整交通

在原有路网上新增或删除步行、机动车和公交线路。

制定政策

深港交流、产业优惠、人才、创业孵化等，由系统转成规范的政策文件。

检查并提交

跑基础检查、调整方案，然后导出两份文件提交。

每个人同样的预算

每位参赛者（或队伍）起始资金相同。建设和政策都要花钱，系统实时显示建设成本、政策成本和剩余资金。

提交前的基础检查

平台内置的基础指标随时告诉你方案的情况，方便你在提交前不断改进。

03 / WHAT YOU SUBMIT

两份文件，一座城市

两份文件都由系统根据你的最终方案自动生成并校验。只有通过格式和基础校验的文件才进入正式测评，组委会据此重建你的方案。

.zip

spatial_plan.zip

城市物理空间规划文件，作为一份完整成果提交：

  • manifest.json：格式版本、坐标参考系、单位、规划边界、底图版本、方案 ID、目标年份 2035 和建设成本汇总
  • plan.gpkg：测评用的结构化数据，包括区域功能、建筑或建筑群、交通网络（含新增和删除的线路）
  • 3d/：用于展示的 3D Tiles 模型，通过统一 ID 与 plan.gpkg 对应
.yaml

policies.yaml

结构化 YAML 格式的政策文本，每项政策写明：

  • 政策 ID、名称、文字介绍和政策目标
  • 目标对象类型、筛选条件、数量及统计口径
  • 单个对象的支持资金和发放方式（非补贴类填 0）
  • 实施区域和实施期限
policies.yaml示例
# one entry per policy
- id: P-03
  name: Young researcher housing subsidy
  description: Monthly rent support for early-career researchers
  goal: Attract and keep research talent in San Tin
  target: { type: resident, filter: "researcher, age ≤ 35" }
  count: { value: 2000, basis: persons per year }
  funding: { per_target: 3000, unit: HKD/month, method: rent subsidy }
  area: San Tin residential zones
  period: 2030–2035
04 / EVALUATION

不只看它长什么样，更看它过得怎么样

每份方案都从两份文件重建，在统一的地图、政策和场景参数下测试。名次综合场景模拟的量化指标、社会模拟 Agent 的评价和专家评审确定。

场景模拟

由 Agent 扮演居民、企业和投资者在你的城市里行动，并结合空间分析评估可达性与覆盖。

Agent 评价

场景跑完后，社会模拟 Agent 根据自己的体验给城市整体打分，形成总体满意度。

专家评审

城市规划、经济、公共政策和人工智能领域的专家，评审创新性、合理性、可实施性与社会价值。

06 / ENGINE

SimuWorld 的底层：经济世界模型

Agentic City 的场景模拟，运行在一个基于经济世界模型（Economic World Model, EWM）的模拟引擎上。家庭、企业、投资机构和政府都是有各自判断与约束的 Agent，它们的决策在市场中相互作用、改变环境，环境又反过来影响下一步决策。

08 / FAQ

常见问题

参赛者常问的问题。

需要会编程吗？

不需要。你通过和 Agent 对话来规划，平台会生成提交文件。有经验的参赛者如有需要，可以使用更丰富的模型接口。

需要懂城市规划或经济学吗？

不需要。好问题比专业术语更重要，比如“这里住了很多年轻人，学校在哪？”模拟会把后果展示给你。

规划哪里？面向哪一年？

北部都会区内以新田、落马洲河套香港园区和牛潭尾为核心的一片连续区域，约 17.73 平方公里。方案面向 2035 年。

到底提交什么？

两份文件，都由平台自动生成并校验：spatial_plan.zip（含 manifest.json、plan.gpkg 和 3d/）以及 policies.yaml。

有预算限制吗？

有。每个人起始资金相同，建设和政策都要花钱。

基础检查的结果就是我的成绩吗？

基础检查是你搭建过程中的参考，名次由场景模拟、Agent 评价和专家评审综合确定。

青少年有单独的赛道吗？

没有。所有人走同一套流程和规则，平台的对话、卡片和自动检查让新手也能完成方案。

可以深港跨境组队、或者从海外参加吗？

都可以。特别鼓励深港跨境组队，也欢迎海外青年团队。

什么时候可以开始搭？

10 月底先上线演示视频和可体验 Demo；完整平台、正式报名与提交预计在 11 月下旬开放。

奖项是什么？

奖项将在比赛正式发布时公布。
