划分区域

用自然语言划出区域，说明功能：居住、商业、办公、公共设施等。

建设建筑

建筑或建筑群，有位置、占地面积、高度和功能。

调整交通

在原有路网上新增或删除步行、机动车和公交线路。

制定政策

将深港交流、产业优惠、人才、创业孵化等写入结构化政策草稿。

检查并提交

复查方案和预算，准备空间包与政策文件，通过比赛提交服务交付。

每个人同样的预算

每位参赛者（或队伍）起始资金相同。建设和政策都要花钱，系统实时显示建设成本、政策成本和剩余资金。

提交前的基础检查

搭建时核对预算和规划检查；Demo 提供示例消防响应记录，方便对照方案查看。

03 / WHAT YOU SUBMIT

两份文件，一座城市

最终交付物由空间规划压缩包和结构化政策文件组成。完成格式、对象 ID、坐标参考、成本与规划约束检查后，组委会据此重建并评估城市。

.zip

spatial_plan.zip

城市物理空间规划文件，作为一份完整成果提交：

  • manifest.json：格式版本、坐标参考系、单位、规划边界、底图版本、方案 ID、目标年份 2035 和建设成本汇总
  • plan.gpkg：测评用的结构化数据，包括区域功能、建筑或建筑群、交通网络（含新增和删除的线路）
  • 3d/：用于展示的 3D Tiles 模型，通过统一 ID 与 plan.gpkg 对应
.yaml

policies.yaml

结构化 YAML 格式的政策文本，每项政策写明：

  • 政策 ID、名称、文字介绍和政策目标
  • 目标对象类型、筛选条件、数量及统计口径
  • 单个对象的支持资金和发放方式（非补贴类填 0）
  • 实施区域和实施期限
policies.yaml示例
policies:
  - id: "P-001"
    name: "Fire service readiness"
    description: "Staff and equip the three planned stations."
    objectives: "Improve emergency access"
    target_type: "fire_station"
    eligibility: ["FS-01", "FS-02", "FS-03"]
    target_count: 3
    counting_basis: "unique_station"
    support_per_target_hkd: 6000000
    payment_method: "implementation_milestones"
    areas: ["NP-025", "NP-081", "NP-168"]
    period: "2030-2035"

参赛成果与经授权收集的运行数据，以及单独授权的 Agent 程序、容器镜像和模型资料，将依照隐私条款与授权范围，用于经济世界模型的训练、评测与持续改进。

04 / EVALUATION

从城市如何运转来评估方案

每份方案都从两份文件重建，在统一的地图、政策和场景参数下测试。名次综合场景模拟的量化指标、社会模拟 Agent 的评价和专家评审确定。

场景模拟

由 Agent 扮演居民、企业和投资者在你的城市里行动，并结合空间分析评估可达性与覆盖。

Agent 评价

场景跑完后，社会模拟 Agent 根据自己的体验给城市整体打分，形成总体满意度。

专家评审

城市规划、经济、公共政策和人工智能领域的专家，评审创新性、合理性、可实施性与社会价值。

九个评估维度

维度核心指标评估方式

我们会跑哪些场景

七类场景产生可量化结果，汇入九个评估维度。社会 Agent 提供总体满意度，专家结合场景结果评审创新性、可实施性与社会价值。

06 / ENGINE

比赛的底层：经济世界模型

Agentic City 的场景模拟，运行在一个基于经济世界模型（Economic World Model, EWM）的模拟引擎上。家庭、企业、投资机构和政府都是有各自判断与约束的 Agent，它们的决策在市场中相互作用、改变环境，环境又反过来影响下一步决策。

08 / FAQ

常见问题

参赛者常问的问题。

需要会编程吗？

从自然语言规划、可视化卡片和引导流程开始。有经验的参赛者也可以使用更丰富的模型接口。

需要懂城市规划或经济学吗？

从具体问题出发，例如“这里住了很多年轻人，学校在哪？”结合城市数据和场景结果逐步完善方案。

规划哪里？面向哪一年？

北部都会区内以新田、落马洲河套香港园区和牛潭尾为核心的一片连续区域，约 17.73 平方公里。方案面向 2035 年。

到底提交什么？

准备两份交付物：spatial_plan.zip（含 manifest.json、plan.gpkg 和 3d/）以及 policies.yaml。

有预算限制吗？

有。每个人起始资金相同，建设和政策都要花钱。

基础检查的结果就是我的成绩吗？

基础检查是你搭建过程中的参考，名次由场景模拟、Agent 评价和专家评审综合确定。

青少年有单独的赛道吗？

所有人走同一套流程和规则。对话、可视化卡片和检查流程帮助新手完成方案。

可以深港跨境组队、或者从海外参加吗？

都可以。特别鼓励深港跨境组队，也欢迎海外青年团队。

什么时候可以开始搭？

交互 Demo 现已开放 ↗，可浏览城市并体验预设规划流程；Track 3 与 Track 1–2 统一于 2026 年 12 月开启。

奖项是什么？

奖项将在比赛正式发布时公布。
