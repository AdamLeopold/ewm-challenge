02 / TRACKS

两个赛道，同一个世界

SimuWorld Challenge 的 Track 1 和 Track 2 都在 HoloBit 世界里进行。可以报一个，也可以两个都报，两个赛道分别排名。

Track 1

策略 Agent

在 Uniswap V3 与 Aave v3 之间管理一笔模拟资金，追求风险调整后的最好收益。

  • 起始 10 万美元模拟资金，USDC 与 WETH 各半
  • 在 Uniswap V3 做流动性和换币
  • 在 Aave v3 存、取、借、还；一份计划内可使用闪电贷
  • 每个模拟小时决策一次，另可订阅事件触发
Track 2

协议风险 Agent

扮演 Aave 的风险管理者：调节风险参数，让协议在压力下保持稳健。

  • 在限定幅度和冷却期内，调整 WETH 与 USDC 储备的风险参数
  • 每 6 个模拟小时决策一次
  • 跑赢“参数不变”的基准：坏账更少、误伤用户更少、协议收入不减
  • 本届聚焦风险参数优化
!

只在仿真里

07 / FAQ

常见问题

如与正式规则不一致，以规则为准。

需要加密货币、钱包或真钱吗？

不需要。一切都在仿真器里运行，不接触任何真实的链。

谁可以参加？

面向全球的开发者、学生和研究者，个人或最多 5 人组队。具体资格见正式规则。

Track 1 和 Track 2 可以都报吗？

可以，两个赛道分别排名。

用什么语言写 Agent？

起步包提供 Python 和 TypeScript 两版。最终提交的是容器镜像，所以镜像里用什么语言都可以。

Agent 可以调用大模型吗？

可以。模型接入方式将随起步包和规则公布。请确保响应足够快，避免超时。

能提前看到压力测试吗？

不能，这正是比赛的核心。练习时你可以、也应该自己构造压力测试。全部正式情景会在决赛后公开。

提交后还能改吗？

冻结前可以多次提交、随时更新；冻结后以签名版本为准，不能再改。

必须写报告吗？

不必须。报告可选，不影响分数。

奖项和奖金是什么？

将随正式规则一同公布。

怎么核对自己的成绩？

决赛后公开种子、情景、记录和核对脚本，你可以自己重新算一遍分数。
