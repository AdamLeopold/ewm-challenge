DeFi 的平行世界

02 / TRACKS

两个赛道，同一个世界

Economic World Model Challenge 的 Track 1 和 Track 2 都在 HoloBit 世界里进行。可以报一个，也可以两个都报，两个赛道分别排名。

Track 1

策略 Agent

在 Uniswap V3 与 Aave v3 之间管理模拟投资组合，在控制回撤、维持账户健康的同时提升收益。

操作范围

  • 起始 10 万美元模拟资金，USDC 与 WETH 各半
  • 在 Uniswap V3 做流动性和换币
  • 在 Aave v3 存、取、借、还；一份计划内可使用闪电贷
  • 每个模拟小时决策一次，另可订阅事件触发
上手步骤
读取余额、仓位和市场观测，生成操作计划，检查执行结果并记录决策。先用下方的借贷教学示例走完这一轮。
交付物
提交签名的 Track 1 容器镜像和 JSON 清单，清单包含固定版本的镜像摘要。具体见下方通用交付清单。
评价方式

S = r − 0.5 × MDD

r 为投资组合净收益率，MDD 为从峰值到谷值的最大回撤，两者使用相同的百分比单位。S 越高越好。隐藏压力题占 80%，前向段占 20%；获奖和决赛资格同时适用生存门规则。

参赛流程
开发与练习 → 热身检查 → 签名冻结 → 压力题与前向段评测 → 成绩复核。
Track 2

协议风险 Agent

扮演 Aave 的风险管理者：管理 WETH 与 USDC 储备，在变化的市场中兼顾协议偿付能力、用户提款流动性和协议收入。

操作范围

  • 调整贷款价值比（LTV）、清算阈值与奖励，以及存款和借款上限
  • 调整利率曲线与储备因子，冻结或解冻储备
  • 每 6 个模拟小时决策一次
  • 按比赛规则与接口定义的参数幅度、冷却期和治理时序执行调整
上手步骤
读取储备利用率、账户健康和市场观测，提出参数调整，检查生效时点，再与参数保持不变的基线比较结果。
交付物
提交签名的 Track 2 容器镜像和 JSON 清单，列出镜像摘要、模型设置和资源需求。两个赛道采用下方同一份通用交付清单。
评价方式
在同一情景、同一种子下，对照参数不变的基线，比较坏账、清算罚金、协议收入和提款流动性损失 W。W 是用户想提款却无法取出的金额乘以持续时间，单位为美元天。隐藏压力题占 80%，前向段占 20%，同时适用生存门规则。
参赛流程
开发与练习 → 热身检查 → 签名冻结 → 与基线配对评测 → 成绩复核。
03 / PARTICIPANT GUIDE

开发、练习、冻结、复核

先用教学示例理解决策循环，再为所选赛道准备 Agent。参赛流程连接本地开发、练习试跑，以及用于正式评测的签名版本。

报名组队

1–5 人一队，选择 Track 1、Track 2 或两个都报。

本地开发

实现观测、决策与执行检查，打包可重复运行的容器。

练习试跑

用练习情景检查决策循环、动作有效性和运行记录。

热身轮

完成热身取得正式赛资格，确认 Agent 已准备就绪。

签名冻结

提交镜像摘要、清单和队伍签名，锁定评测版本。

评测与复核

运行隐藏压力题和前向段，核对成绩，再进入决赛。

你来构建

智能层

  • 策略或风险逻辑
  • 监控与恢复机制
  • 处理观测、动作与执行结果
  • 练习用的自建压力测试
比赛框架

评测层

  • 协议数字孪生与统一接口
  • 练习情景与历史数据
  • 隐藏压力情景
  • 计分与结果核实
提交什么
  • 一个 OCI 容器镜像（不超过 4 GB，linux/amd64）
  • 一份 JSON 清单：队伍标识、赛道、固定版本的镜像摘要、模型设置、订阅事件与资源需求
  • 队伍的 OpenSSH ed25519 签名，用于验证冻结提交物
  • 可选报告与说明材料用于交流；评测分数来自 Agent 运行
关于大模型

Agent 可以调用大模型。请在清单中声明模型配置，按比赛的模型接入设置运行，并在时限内完成每次决策。

07 / FAQ

常见问题

参赛者常问的问题。

Agent 在哪里运行？

比赛使用 HoloBit 数字孪生中的模拟账户与余额。下方借贷教学示例直接在浏览器运行。

谁可以参加？

面向全球的开发者、学生和研究者，个人或最多 5 人组队。具体资格见正式规则。

Track 1 和 Track 2 可以都报吗？

可以，两个赛道分别排名。

用什么语言写 Agent？

选择适合 Agent 的语言。提交的 linux/amd64 容器需实现比赛接口，并包含运行所需的依赖。

Agent 可以调用大模型吗？

可以。起步包和规则定义模型接入方式；请在清单中声明模型配置，并在时限内完成决策。

怎样准备压力测试？

练习时自建压力情景，检查 Agent 的响应。正式测试在冻结后生成，情景与核对材料在决赛后公开。

何时可以更新 Agent？

冻结前可以更新并重新提交。此后评测使用签名清单与镜像摘要锁定的版本。

报告有什么用途？

报告与说明材料可选，用于介绍方法与交流经验。比赛分数来自 Agent 的评测运行。

奖项和奖金是什么？

奖项将在比赛正式发布时公布。

怎么核对自己的成绩？

决赛后使用公开的种子、情景和核对记录重算分数。经授权数据与资料的研究使用遵循“数据与研究用途”页面所述的授权选项。
