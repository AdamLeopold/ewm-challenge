金额均为虚拟记账单位。净值 = 抵押品价值 + 现金 − 债务。
01 / 设置实验

选择你的 Agent

55 · 下跌更深100 · 价格回升

市场路径：100 → 80 → 60。这是你设置的测试；Agent 看不到未到来的轮次。

本题规则

80% 清算线：债务 ÷ 抵押品价值超过 80% 就清算。

10% 额外成本：教学版一次清偿全部债务，并消耗债务金额 10% 的抵押品。

Agent 每轮只可还款或等待。先更新价格，再决策，最后检查清算。忽略利息、手续费和真实协议细节。

哪些是老师的方向，哪些是本例添加的？
老师初稿的方向：持续运行的 Agent、统一仿真、压力测试、可追踪记录、同时关注收益和风险。
本教学例自拟：100 / 50 / 20 的账户、60% 提前还款线、80% 清算线、10% 成本、两轮价格、两个规则 Agent、50 / 30 / 20 评分。未获老师确认。它也没有实现初稿提出的 40% 实时评测 / 60% 隐藏压力测试。
正式落地前需确认：协议与模型精度、动作顺序、AI Agent 资格、允许的仿真调用、评分公式，以及真实 HoloBit 的可用接口。
